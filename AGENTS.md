# Repository instructions

## Commit messages

- Use Conventional Commits: `<type>[optional scope][!]: <description>`.
- Choose a type that matches the change, such as `feat`, `fix`, `docs`, `refactor`, `test`, or `chore`.
- Write a concise, imperative description, for example `fix(a11y): support keyboard uploads`.
- Keep each commit focused on a coherent change and exclude temporary artifacts.
